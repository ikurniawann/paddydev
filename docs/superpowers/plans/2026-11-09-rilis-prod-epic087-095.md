# Rilis Production EPIC-087..095 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membawa semua epic yang sudah selesai dan lulus QA staging (EPIC-087 s.d. EPIC-095, PR #75–#82 dan #84, ditambah docs #85) ke main lalu ke production `paddyadorable.biz.id`. Hambatan yang ditemukan saat pengecekan diperbaiki dulu.

**Architecture:**
- Satu branch rilis `release/prod-20261109` dari main menggabungkan semua branch epic dengan merge commit, sehingga CI berjalan sekali pada gabungan yang sama persis dengan yang akan live. Setelah PR rilis di-merge, GitHub menandai PR epic sebagai merged karena head-nya ikut masuk main.
- Production di-deploy dengan pola biasa: `git archive` main ke `~/paddydev-src` di VPS, lalu `tools/deploy-paddydev.sh`, yang menerapkan migrasi sebelum mengganti container dan rollback otomatis bila gagal.
- Sebelumnya ada gladi migrasi di salinan DB production.

**Tech Stack:** Go (`backend/`), Next.js (`frontend/`), Postgres 17, Docker di VPS, GitHub Actions CI.

**Spec:** Permintaan user 09-11-2026: "PR dan merge yang sudah done dan tidak error atau bug agar terbawa ke paddy-prod … cek jika ada dan lakukan pekerjaan ulang epic tersebut". Hasil pengecekan ada di bagian *Temuan pengecekan* di bawah. Epic acuan: `docs/epics/EPIC-087` … `EPIC-095`.
